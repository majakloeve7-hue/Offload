OFFLOAD PWA

This version is installable like an app after it is hosted on HTTPS.

FILES TO UPLOAD
- index.html
- manifest.webmanifest
- sw.js
- icons/ folder

GITHUB PAGES
1. Create a public GitHub repository called offload.
2. Upload ALL files and the icons folder from this package.
3. Open Settings > Pages.
4. Choose "Deploy from a branch".
5. Choose branch: main, folder: /(root).
6. Save and wait for the Pages website address.

INSTALL ON IPHONE / IPAD
1. Open the published Offload website in Safari.
2. Tap Share.
3. Tap "Add to Home Screen".
4. Tap Add.
5. Offload will appear with its own icon and open in an app-style window.

INSTALL ON ANDROID
1. Open the published website in Chrome.
2. Open the browser menu.
3. Tap "Install app" or "Add to Home screen".
4. Confirm.

NOTE
Opening index.html directly from the Files app will still look like a document.
The PWA/app behavior works after the folder is hosted on a real HTTPS website such as GitHub Pages.
